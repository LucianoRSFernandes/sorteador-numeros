Projeto Sorteador
1. Introdução
Este projeto consiste no desenvolvimento de uma aplicação web simples, focada em reforçar os fundamentos de HTML, CSS e JavaScript. O objetivo principal é criar um sorteador de números aleatórios com base em valores fornecidos pelo usuário.

2. Ferramentas Utilizadas
A IDE (Ambiente de Desenvolvimento Integrado) escolhida para este projeto é o VS Code, devido à sua excelente interação com as linguagens de programação envolvidas (HTML, CSS e JavaScript).

3. Estrutura do Projeto
O projeto é iniciado com uma estrutura base de arquivos pré-definida, que inclui:

img/: Pasta contendo as imagens utilizadas na aplicação.

app.js: Arquivo JavaScript, inicialmente vazio, onde será implementada a lógica do sorteador.

index.html: Arquivo HTML que define a estrutura da página web.

style.css: Arquivo CSS responsável pela estilização da interface.

Essa estrutura pode ser visualizada e navegada através do explorador lateral de arquivos do VS Code.

4. Visualização do Projeto
Para visualizar o projeto no navegador, é recomendável utilizar a extensão Live Server do VS Code. Com o projeto aberto no VS Code, basta clicar com o botão direito no arquivo index.html e selecionar a opção "Open With Live Server". Isso abrirá o projeto no navegador padrão da sua máquina, permitindo acompanhar as alterações em tempo real.

5. Funcionalidades
O projeto "Sorteador" apresenta as seguintes funcionalidades principais:

Formulário de Entrada: Um formulário simples com três campos de entrada para que o usuário insira os valores desejados para o sorteio.

Botão "Sortear": Ao clicar neste botão, o código JavaScript é acionado para ler os valores digitados, gerar números aleatórios dentro do intervalo especificado e exibi-los na tela.

Botão "Reiniciar": Localizado à direita do botão "Sortear", este botão limpa os campos do formulário, permitindo que o usuário inicie um novo sorteio.

O código JavaScript será responsável por toda a lógica de leitura dos valores, o algoritmo de geração de números aleatórios e a manipulação do DOM para exibir os resultados.
